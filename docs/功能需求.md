## 1. 产品概述

`Screenshot-rs` 是一款跨平台桌面截图工具，面向需要快速截取屏幕区域并进行轻量标注的用户。产品形态为常驻系统托盘的后台程序，用户通过全局热键或托盘菜单触发截图，完成后自动将带标注的图像写入系统剪贴板，可直接粘贴到聊天软件、编辑器或浏览器中。

**功能参考基准：微信截图（Alt+A）** —— 本产品的功能集、交互流程、工具栏布局以微信截图作为对标参考，包含但不限于区域选择、矩形/箭头/画笔/文字/马赛克标注、撤销重做、长截屏、OCR 文字识别等。

核心价值：

- **零启动延迟**：通过全局热键直接进入截图状态，无需先打开主界面。
- **截图即标注**：截图完成后可立即在选区内绘制标注，无需切换到其他工具。
- **无文件落地**：截图结果直接进剪贴板，省去保存/打开文件的步骤。
- **长截屏**：对长网页、长聊天记录、长文档等内容可一键滚动截取。
- **OCR 识别**：截图中包含的文字可一键提取为可编辑文本。



## 3. 功能需求

### 3.1 触发方式

| 编号 | 功能 | 描述 |
|------|------|------|
| F-01 | 全局热键启动 | 用户在任何应用中按 `Alt+S` 唤起截图覆盖层 |
| F-02 | 托盘菜单启动 | 点击系统托盘图标 → 菜单 → "截图" 启动 |
| F-03 | 托盘退出 | 点击托盘菜单 → "退出" 结束程序 |
| F-04 | 取消截图 | 截图过程中按 `Esc` 键取消，不写入剪贴板 |

### 3.2 区域选择

| 编号 | 功能 | 描述 |
|------|------|------|
| F-05 | 鼠标拖拽选区 | 按下鼠标拖拽出一个矩形选区 |
| F-06 | 选区最小尺寸 | 允许任意大小选区（含 1×1 像素） |
| F-07 | 选区可视化 | 选区外的屏幕区域显示半透明遮罩（dim）以突出选区 |
| F-08 | 选区完成 | 松开鼠标后选区确定，进入标注编辑模式 |

### 3.3 标注工具栏

工具栏悬浮显示在选区下方，包含以下工具按钮：

| 编号 | 工具 | 描述 |
|------|------|------|
| F-09 | 矩形 | 在选区内绘制空心矩形（描边） |
| F-10 | 箭头 | 绘制带箭头的直线 |
| F-11 | 画笔 | 自由手绘线条 |
| F-12 | 文字 | 在选区内点击，输入文字并保留为图层 |
| F-13 | 马赛克 | 将选区内指定矩形区域打马赛克（块状模糊） |
| F-14 | 取色器 / 调色板 | 选择当前绘图颜色（HSV 调色板） |
| F-15 | 撤销 / 重做 | 撤销或重做最近一次标注操作 |
| F-16 | 加粗切换 | 切换文字工具的加粗/常规 |
| F-17 | 字号选择 | 文字工具的字号档位：16 / 20 / 24 / 32 / 48 像素 |
| F-18 | 完成 | 关闭覆盖层，将带标注的选区图像写入剪贴板 |
| F-19 | 取消 | 关闭覆盖层，不写入剪贴板 |

### 3.4 文字输入

| 编号 | 功能 | 描述 |
|------|------|------|
| F-20 | IME 中文输入 | 文字工具必须支持中文输入法（拼音、五笔等）组合输入 |
| F-21 | 折行 | 文字超出选区宽度时自动折行（不溢出选区） |
| F-22 | 颜色与字号 | 文字颜色取当前调色板颜色，字号取工具栏选中值 |

### 3.5 输出

| 编号 | 功能 | 描述 |
|------|------|------|
| F-23 | 自动复制到剪贴板 | 截图完成后，图像自动写入系统剪贴板，格式为 RGBA PNG |
| F-24 | 跨应用粘贴 | 剪贴板内容应能被任意应用（Slack、浏览器、编辑器、IM）正确粘贴为图像 |

### 3.6 长截屏

参考微信"长截图"功能：

| 编号 | 功能 | 描述 |
|------|------|------|
| F-25 | 启动长截屏 | 用户在区域选择后选择"长截图"模式，或在编辑模式切换到长截屏 |
| F-26 | 自动滚动拼接 | 系统自动向下滚动屏幕内容并拼接多帧为一张长图 |
| F-27 | 滚动速度可调 | 用户可调整自动滚动速度（慢/中/快） |
| F-28 | 手动控制滚动 | 用户可通过鼠标滚轮或快捷键控制向下/停止滚动 |
| F-29 | 重复内容去重 | 长截图中相邻帧的相同部分自动去重，避免冗余 |
| F-30 | 中途停止 | 用户可随时点击"完成"或按快捷键停止长截屏 |
| F-31 | 长截图标注 | 长截屏完成后支持标准标注工具（矩形/箭头/文字等） |
| F-32 | 长图输出 | 最终长图写入剪贴板，可直接粘贴 |

### 3.7 OCR 文字识别

参考微信"提取文字"功能：

| 编号 | 功能 | 描述 |
|------|------|------|
| F-33 | 一键 OCR | 截图完成后工具栏提供"提取文字"按钮 |
| F-34 | 识别范围 | 默认对整个选区进行文字识别；支持手动框选识别子区域 |
| F-35 | 多语言 | 至少支持中文（简/繁）、英文；可扩展其他语言 |
| F-36 | 识别结果展示 | 识别结果以弹窗或侧边栏形式展示为可编辑文本 |
| F-37 | 一键复制 | 识别结果可一键复制到剪贴板 |
| F-38 | 行内编辑 | 识别结果允许用户在线修正错字 |
| F-39 | 隐私 | OCR 在本地完成，不上传截图到云端 |

### 3.8 微信截图风格扩展工具

参考微信截图提供的额外标注能力：

| 编号 | 功能 | 描述 |
|------|------|------|
| F-40 | 椭圆工具 | 在选区内绘制空心椭圆 |
| F-41 | 序号标注 | 提供 1, 2, 3... 数字气泡，用于步骤说明 |
| F-42 | 贴图 | 将选区图像提取为可拖动的"贴纸"留在屏幕上 |
| F-43 | 隐藏当前窗口截图 | 截图前自动隐藏当前活动窗口（避免截到截图工具自身） |
| F-44 | 保存到文件 | 除剪贴板外，支持将图像保存为 PNG/JPG 到本地文件 |
| F-45 | 多显示器支持 | 支持多显示器分别截图或全屏跨屏截图 |

## 4. 用户主流程

### 4.1 截图 + 标注 + 输出

```
用户在任意应用 → 按 Alt+S
   ↓
屏幕被 dim 遮罩 → 鼠标拖拽选区
   ↓
选区确定 → 工具栏出现在选区下边缘
   ↓
[可选] 用户点击工具按钮绘制标注 → 撤销/重做微调
   ↓
用户点击 "完成"
   ↓
覆盖层关闭 → 图像写入剪贴板
   ↓
用户切换到目标应用 → Ctrl+V 粘贴图像
```

### 4.2 取消流程

```
用户在任意应用 → 按 Alt+S → 拖拽选区 → 按 Esc
   ↓
覆盖层关闭 → 剪贴板内容不变
```

## 5. 验收标准（MVP Done）

满足以下全部条件视为 MVP 验收通过：

- [ ] 启动应用，系统托盘图标出现
- [ ] 按 `Alt+S`，覆盖窗口出现，屏幕被 dim
- [ ] 鼠标拖拽出选区，工具栏出现在选区下边缘
- [ ] 矩形、箭头、画笔、文字、马赛克 5 个绘图工具均可使用
- [ ] HSV 调色板可切换当前颜色
- [ ] 撤销 / 重做工作正常
- [ ] 点"完成" → 关闭覆盖窗口 → 粘贴到任意应用能看到带标注的图像
- [ ] 按 `Esc` 取消截图，不污染剪贴板
- [ ] 在 Windows 10/11 上能正常运行
- [ ] 在 Ubuntu 22.04（X11 会话）上能正常运行

## 8. 已知限制（产品层面，非实现）

### 8.1 v0.1 MVP 限制

- 仅截取主显示器，不支持多显示器分别截图
- 截图结果仅进剪贴板，不保存到本地文件
- 文字工具不支持字体选择，仅使用内置字体（思源黑体）
- 马赛克仅支持矩形区域，不支持自由形状
- 撤销栈无大小限制，理论上可无限撤销

### 8.2 长截屏限制（v0.3 计划）

- 仅支持垂直滚动方向，不支持横向滚动
- 仅对可滚动窗口生效，固定画面重复滚动会被去重丢弃
- 最大长度受可用内存限制

### 8.3 OCR 限制（v0.4 计划）

- 手写体、艺术字体、低分辨率截图识别准确率下降
- 表格、复杂排版识别后需用户手动调整
- 早期版本仅支持中/英，扩展语言需后续版本
